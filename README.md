# OnthologyEditor

Editor de ontologías para ALEPH Scriptorium con soporte para el template Flove/Iowa.

## Instalación

```bash
npm install
```

## Uso

```bash
npm run dev
```

## Documentación

Ver [README-SCRIPTORIUM.md](./README-SCRIPTORIUM.md) para la integración con el Scriptorium.
